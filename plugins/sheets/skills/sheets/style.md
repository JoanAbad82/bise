# How a sheet should look

A sheet is a tool someone will use, sort and change after you. Make it
easy to read and hard to break.

## Layout

- One table per sheet, starting at A1. A title above it only when the
  file has several sheets that need telling apart; the sheet name usually
  does that job.
- Row 1 is the header: short names, the unit in the name when there is
  one (`Revenue (k€)`, `Days`). Bold, a light fill (`#f2f2f2`), a thin
  border. No merged cells in the header: they break sorting and filters.
- One kind of thing per column, one record per row. No blank rows or
  columns inside the table.
- Totals go in a row below the data, labelled `Total`, bold. Not inside
  the data, not at the top.
- A summary or a chart-ready block goes on its own sheet, first in the
  tabs, reading the data sheet with formulas.
- Sheet names: short, plain, no dates in them unless the file is a
  series by date (`Q3`, `Costs`, `Summary`).

## Numbers

- Store numbers as numbers and dates as dates, never as text. Show them
  with a number format, not by rounding the value.
- One format per column: `#,##0` for counts and money without cents,
  `#,##0.00` with cents, `0.0%` for shares, `yyyy-mm-dd` for dates. A
  currency sign in the format (`"€"#,##0`) or in the header, not both.
- Right-aligned numbers (the default), left-aligned text.
- Totals, shares and growth are formulas that point at the data. A number
  typed where a formula belongs is wrong the day someone changes a cell.
- Inputs (numbers someone is meant to change) can get a pale fill
  (`#fff8e1`) when the sheet mixes inputs and results; say so in a note
  on the header.

## Width and color

- Widen a column to its longest value (about 1 character per unit of
  `width`), no wider. Wrap long text (`wrap: true`) instead of a 60-wide
  column.
- Color only to carry meaning: the header, inputs, a cell that needs
  attention. No rainbow rows, no colored text for decoration, no more
  than two fills in a table.
- Default font and size. Bold for the header and the totals only.

## Words

- Labels are plain words a reader knows: `Region`, `Revenue`, not
  `rgn_cd` or `Rev. (adj.)`.
- A note on a cell (`.note(...)`) for a source or an assumption, one
  sentence. Not for decoration.
- No filler cells: no "Generated by", no "Notes: N/A", no empty "Comments"
  column nobody asked for.

## Before you say done

- `check()` is clean or each warning is named in your reply.
- Every total and ratio is a formula; its value shows (no `no_value`
  where a supported function would do).
- The header is the first row, the units are in it, the widths fit.
- You told the user what you changed in one or two lines, by sheet and
  range (`Revenue!D3: 91 → 95, the Q3 total follows`).
