# acme CLI

The command line for acme (invented QA fixture code: the QA hub's workspace, never a real product).

- `install.sh`: installs `acme` in `~/.acme/bin` and adds it to the PATH.
- `acme/http.py`: the HTTP client every API call goes through.
- `acme/sync.py`: `acme sync`, the team's plans into the local cache.
- `acme/assistant.py`: the in-app assistant's prompt.
