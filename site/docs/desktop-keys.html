keys and menus

the keys of bise desktop, from any app, in the window, the composer and the inbox. ⌘/ shows the same list in the app.

only in bise desktop in bise terminal: keys and commands ›

⌘/ shows this list over the window, and settings › keys has it too. every key of bise terminal that makes sense in a window works here; ⌘ adds a Mac app's gestures.

#from any app

keywhat it does
hold fntalk to bise, with what is in front of you
fn fnhands-free voice; fn again stops
fn spacethe spotlight: find an agent, or ask bise

see voice and fn.

#the window

⌘1 … ⌘9a project, in the order of settings › projects
⌥0 / ⌥1 … ⌥9the project's main / an agent
⌥↑ / ⌥↓the previous / next agent (the composer empty)
⌘Kfind an agent, a page or an artifact
⌘[ / ⌘]back / forward
⌘Ithe inbox: what waits for you, most blocking first
⌘Ffind in the thread
⌘Dthe agent's changes
⌘⇧Athe artifacts

ctrl+ycopy a code block
⌘Nadd a project
⌘\show or hide the sidebar
⌥⌘0show or hide the right bar

⌘,settings
⌘/this list

#the composer

keywhat it does

⌘.stop the agent's turn
