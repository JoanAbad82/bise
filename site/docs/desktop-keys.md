`⌘/` shows this list over the window, and settings › keys has it too. every key of bise terminal that makes sense in a window works here; `⌘` adds a Mac app's gestures.

## from any app

| key | what it does |
|---|---|
| `hold fn` | talk to bise, with what is in front of you |
| `fn fn` | hands-free voice; `fn` again stops |
| `fn space` | the spotlight: find an agent, or ask bise |

see [voice and fn](voice).

## the window

| key | what it does |
|---|---|
| `⌘0` | bise |
| `⌘1` … `⌘9` | a project, in the order of settings › projects |
| `⌥0` / `⌥1` … `⌥9` | the project's main / an agent |
| `⌥↑` / `⌥↓` | the previous / next agent (the composer empty) |
| `⌘K` | find an agent, a page or an artifact |
| `⌘[` / `⌘]` | back / forward |
| `⌘I` | the inbox: what waits for you, most blocking first |
| `⌘F` | find in the thread |
| `⌘D` | the agent's changes |
| `⌘⇧A` | the artifacts |
| `⌘E` | unfold / fold everything (`ctrl+o` too) |
| `ctrl+y` | copy a code block |
| `⌘N` | add a project |
| `⌘\` | show or hide the sidebar |
| `⌥⌘0` | show or hide the right bar |
| `` ctrl+` `` | show or hide the terminal panel |
| `⌘,` | settings |
| `⌘/` | this list |

## the composer

| key | what it does |
|---|---|
| `⏎` | send; during a turn, steer it |
| `⇧⏎` | a new line |
| `tab` | during a turn: queue it for the end of the turn |
| `↑` | in an empty composer: your queued or last message back |
| `ctrl+c` | stop the turn |
| `⌘.` | stop the agent's turn |
| `esc` | put the draft away; close what is open |
| `⇧⇥` | switch the [approvals](approvals) mode: yolo / auto |
| `/` | commands |
| `@` | a file |
| `$` | a skill |
| `⌘V` | paste text, an image, or a long text as a chip |
| `ctrl+r` | dictation into the composer |

## the inbox

| key | what it does |
|---|---|
| `↑` `↓` | the previous / next item |
| `ctrl+p` / `ctrl+n` | the previous / next item, round from the last to the first |
| `ctrl+o` | open the item's folded lines |
| `←` `→` | walk the item's options |
| `1` … `9` | pick that option |
| `⏎` | pick the option on, or send your typed answer |
| `⌘⌫` | close it without answering |
| `esc` | back |

## the menus

| menu | what it has |
|---|---|
| bise | About, **Settings…** (`⌘,`), Hide, **Quit** (`⌘Q`) |
| File | **Save a Copy…** (`⌘S`, the open artifact), Close |
| Edit | undo, the clipboard, **Find** (`⌘F`) |
| Go | **Inbox** (`⌘I`) |
| View | **Terminal** (`` ctrl+` ``) |
| Window | macOS's own |

the `:*` in the menu bar has its own menu: what is at work and waiting, the inbox, your projects, **open bise**, **inbox**, **settings…**, **quit bise**. a right click gives the short one: open bise (`⌘0`), settings (`⌘,`), quit (`⌘Q`).
