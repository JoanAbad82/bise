bise docs

bise runs a team of AI agents for you. you talk to one agent, main, and it runs the others. two apps, the same agents.

you talk to main, your team lead. main turns what you ask into tasks and starts one agent per task. the agents work in parallel, talk to each other, and land their work in your repo. what needs you waits in your inbox.

#two apps, one bise

bise desktopbise terminal
what it isa window on your Mac: every project in one window, an inbox for what needs you, the bims at workin your terminal, one thread per repo, keys for everything
runs onMacs with Apple silicon, macOS 14 or latermacOS and Linux, over SSH too
how you talktype, or hold fn in any apptype, or ctrl+r
get itdownload itone curl line

both apps run the same agents, with the same threads, models, keys and settings. use one, or both at once on the same repo.

these docs are one set for both. most of it is the same in both apps. where a step differs, the page shows your app's way: pick yours with the desktop / terminal switch at the top of the list of pages. a page that exists in one app only says so under its title.

#start here

  1. get bise: bise desktop or bise terminal.
  2. give it a model: an API key from a provider, or a plan you already pay for, through a subscription.
  3. ask main for something. read main and the agents to see what happens next.

#for agents

every page is also plain Markdown: add .md to its address, for example bise.dev/docs/providers.md. to have a coding agent install and set up bise terminal for you, give it bise.dev/setup.md.

#requirements

bise desktop runs on Macs with Apple silicon, macOS 14 or later. bise terminal runs on macOS (Apple silicon and Intel) and on Linux (x86_64 and arm64, glibc 2.34 or newer). you need git; on Linux, OpenSSL 3 too. see start with bise terminal for the Linux details.
